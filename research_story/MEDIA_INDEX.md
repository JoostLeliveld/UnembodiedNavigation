## Chapter views (the browsable layer)

Every chapter folder has `figures/` and (where applicable) `videos/` containing **relative
symlinks** into the two homes — curated to what an examiner should see. Rebuild after adding
media:

```bash
python3 research_story/_tools/link_media.py   # idempotent; errors on dangling targets
```

Current coverage: 68 figures + 16 videos across chapters 00–03, 05–09. Chapters 04/10/11
have no media yet by design. What each chapter still LACKS is tracked in

## Rules

- New locked figure → `paper_artifacts/figures/` (+ provenance JSON). New study figure →
  `logs/studies/<study>/`. **Never** a third location; never copy between homes — link.
- Bulk media (frame dumps, videos) never in git-tracked paths; only final montages/figures
  are committed.
- Data-source labels on every figure/video: `BELIEF` / `PIXEL` / `MODEL` / `GT — evaluation only`.
