Starter prompts for the custom GPT
==================================

Use these after uploading the context files.

Prompt 1: Draft the paper skeleton
"Using the uploaded context, draft an IWAI/LNCS-style paper skeleton in LaTeX. Keep the current thesis-report notation. Include section headings, subsection headings, and 2-4 sentence intent notes per subsection. Do not invent results. Mark planned experiments clearly."

Prompt 2: Rewrite the introduction
"Rewrite the introduction for an IWAI paper in the style of the uploaded thesis-report. The introduction should motivate external-camera visibility-aware navigation, explain why EFE is a natural framework, and end with careful contributions. Do not overclaim beyond the current case-study evidence."

Prompt 3: Tighten the method
"Write a concise method section explaining how the learned YOLO-score GP enters the EFE planner through `R_eff`. Include equations for the GP target, logit fit, conservative map, precision blend, risk, and ambiguity. Keep caveats local to the relevant equations."

Prompt 4: Design the experiment section before running experiments
"Draft the experimental protocol section for the planned comparison. Use the uploaded experiment blueprint. Make clear what is fixed across methods, what changes, what metrics are primary, and how invalid/interrupted runs are handled."

Prompt 5: Write preliminary-results wording
"Draft a preliminary case-study results paragraph using `experiment_20260422_180449` and `experiment_20260423_111758`. Treat them as legacy case-study runs, not final `shadow_tradeoff_a` validation. Mention that older near-goal `stuck` labels are not clean aggregate successes, while current runs log goal-region entry separately."

Prompt 6: Create a claims audit
"Review the current draft and list every sentence that overclaims. For each one, propose a more precise replacement consistent with the uploaded claims-and-caveats file."

Prompt 7: Make the contribution sharper
"Given the uploaded method and caveats, propose three alternative contribution lists. Each list must distinguish active-inference method contributions from engineering implementation details."

Prompt 8: Prepare supervisor questions
"List the ten most likely critical questions a supervisor or IWAI reviewer would ask about this paper, and draft concise technical answers grounded only in the uploaded files."

Prompt 9: Brainstorm the final experiment campaign
"Using `claude_handoff_context.txt` and the current thesis sections, propose a final IWAI experiment protocol. Be critical: identify which baselines are necessary, which are overkill, which metrics should be primary, how to treat stuck/interrupted/invalid runs, and what plots belong in the main paper versus appendix. Do not assume runtime multistart seeding exists."

Prompt 10: Metrics sanity check
"Audit the proposed metrics for whether they actually support the central claim: learned state-dependent observation covariance changes EFE planning compared with constant observation covariance. Separate task metrics, safety metrics, state-estimation metrics, and EFE diagnostics. Recommend a minimal table and minimal figure set for a short IWAI paper."
