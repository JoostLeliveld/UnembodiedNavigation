# Archive

This folder holds repository material that is intentionally kept for historical context but is not part of the active thesis-facing code path.

## What Belongs Here

- legacy task aliases kept only so older notes or manifests can still be interpreted
- abandoned visualization or dashboard remnants
- any future notes or support files that should not appear inside the active `src/` tree

## What Does Not Belong Here

- current launch files
- active planner, perception, state, or experiment code
- files required to run the main comparison

New readers should ignore this folder on a first pass.
