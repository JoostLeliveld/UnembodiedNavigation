PROJECT OVERVIEW
================================================================================
A ROS 2 robotics project implementing navigation, planning, and control for a
TurtleBot3 Waffle Pi robot using Gazebo Harmonic simulator. The project is
organized as a colcon workspace with multiple ROS 2 packages for different
functionalities.

NAMING CONVENTIONS & STANDARDS
================================================================================

1. PACKAGE NAMING
   ✓ Correct: All packages use lowercase, snake_case (ROS 2 standard)
     Examples: control, estimation, mapping, perception, planning, sim, etc.

2. FILE NAMING
   ✓ Correct: Python files are lowercase_with_underscores
     Examples: astar_planner.py, rviz.launch.py, sim.launch.py
   
   ✓ Correct: URDF/Xacro files use extension: .urdf.xacro
   
   ✓ Correct: SDF files use extension: .sdf
   
   ✓ Correct: Configuration files are YAML or JSON in config/ directories

3. DIRECTORY NAMING STANDARDS (ROS 2 Python packages)
   ✓ Correct:
     - launch/        - Contains .launch.py files
     - config/        - Contains configuration files
     - resource/      - Package metadata
     - <package_name>/ - Python module matching package name

4. PYTHON NAMING
   ✓ Correct: Node classes use CamelCase
     Example: AStarPlanner, RobotStatePublisher

5. ROS 2 NAMING
   ✓ Correct: Topic/service names use lowercase with slashes
     Example: /robot/odom, /robot/cmd_vel

6. MESH/URDF NAMING
   ✓ Correct: Model paths use model:// URI scheme
     Example: model://sim/robot_description/meshes/...
